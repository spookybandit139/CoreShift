# CoreShift Terms Site

This folder is a portable static website for the CoreShift Terms of Service.

## Preview

Open index.html in a modern browser. No server, build command, package manager, or external asset is required.

## Publish

Upload the three public files—index.html, styles.css, and app.js—to any static host. Keep them in the same directory.

## Before public release

Have qualified counsel review the Terms for the operator's location, audience, database hosting model, privacy practices, consumer-law obligations, and distribution plan. Replace or supplement the in-app contact route with a monitored legal/privacy email or postal contact if required.
