# CoreShift 1.10.0 — FPS Booster Ultra

This release keeps the CoreShift 1.9.1 interface and upgrades only the FPS Booster channel.

## Measured memory cleanup

- Displays the real amount of background process working memory released.
- Shows the number of accessible processes trimmed and the number of optimizations applied.
- Protects Windows shell, security, audio, desktop, and CoreShift processes.
- Does not terminate applications or falsely label the Windows standby cache as unused RAM.

## Saved gaming profile

- Every booster option is free and saved locally on the PC.
- Choose a game executable for Auto-Boost detection.
- Use Boost & Launch to apply the saved profile before starting the game.
- Auto-Boost applies the profile when the selected game starts and restores the previous state after it closes.

## Reversible session controls

- Temporary gaming power plan.
- CPU core-parking preference.
- Optional low-latency CPU idle policy with a heat/power warning.
- Windows Game Mode.
- Game DVR background-capture control.
- Background RAM working-set cleanup.
- Clipboard cleanup.
- Sticky Keys shortcut control.
- Legacy Cortana/search-assistant policy.
- Background app restriction.
- Optional Windows problem-reporting pause.
- Diagnostic personalization reduction.
- Notification-toast quiet mode.

CoreShift backs up changed user registry values, restores the previous power scheme, deletes its temporary plan, and restores changed settings through **Restore now** or when the app closes.
