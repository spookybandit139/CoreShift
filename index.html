VPN rotation scheduler

CoreShift uses a Windows VPN profile and credentials saved by Windows. It never stores your VPN password.

Select a detected VPN profile to begin.
What this actually changes

A VPN reconnect can change the public address websites see. It does not alter your ISP account or guarantee a new address—the VPN provider may reconnect to the same exit server. Windows DHCP renewal only refreshes a local network address, so CoreShift does not mislabel that as public-IP rotation.

Rotating disconnects active games, voice calls, downloads, and remote database sessions for a short time.
